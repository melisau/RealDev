# RealDev landing page

The live RealDev site at https://realdev.melisauyar5225.chatgpt.site is the active visual reference. The previous navy concept is superseded by the user's request to reuse the site's existing visual language.

Use the original CSS rules exported from the live site's same-origin CSSOM, without changing its theme variables. Light: canvas #f6f8fa, paper #ffffff, ink #1f2328, border #8c959f, accent #6f42c1. Dark: canvas #1b2028, paper #252b34, ink #f0f6fc, border #6f7885, accent #986eee. Teal #48d1cc is reserved for feedback. All component corners are square; shadows are hard offsets, with no blur.

Typography: Major Mono Display for the brand and large headings, Share Tech Mono for UI controls and section subheadings, Plus Jakarta Sans for body copy. Turkish is the first-visit default; full English switching remains available. The theme preference uses the existing site's realdev-theme storage key.

Three major surfaces: split hero with interactive quiz; open learning path rows and three-step learning process; closing free-learning CTA and footer.

Buttons and learning previews remain native HTML. All examples are local demonstrations, with no arbitrary user-code execution.

Intentional layout adaptation: the existing site's large rectangular public hero is adapted to a two-column hero with a working quiz preview. Exact brand tokens, square borders, offset shadows, and type families remain inherited. The header includes the existing site's actual sign-in route.
